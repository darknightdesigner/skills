# Engineering

Code and repo workflow skills.

- **[new-session](./new-session/SKILL.md)** - Create and publish a unique branch from the latest `origin/main`.
- **[no-use-effect](./no-use-effect/SKILL.md)** - Replace direct `useEffect` calls with derived state, event handlers, data fetching, `useMountEffect`, or key resets.
- **[publish-pr](./publish-pr/SKILL.md)** - Publish a ready-for-review PR and follow through until checks pass and conflicts are resolved.
- **[respond-code-review](./respond-code-review/SKILL.md)** - Verify PR review feedback before acting, then fix, propose options, or reply.
