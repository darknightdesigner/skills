# Repo Instructions

Skills are organized under `skills/` by bucket.

Stable skill buckets:

- `engineering/`
- `framer/`
- `productivity/`
- `misc/`

Non-stable buckets:

- `personal/`
- `in-progress/`
- `deprecated/`

Stable skills should be listed in `.claude-plugin/plugin.json` and linked from `README.md`. Non-stable skills should stay out of both.

Every skill directory should contain `SKILL.md`. See `docs/invocation.md` for invocation metadata.
